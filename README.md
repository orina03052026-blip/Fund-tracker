# Fund Tracker

投資・資金運用の入出金と運用損益を記録するシンプルなWebアプリ。

- 公開/ローカルどちらでも `index.html` を開くだけで動作（ビルド不要・依存ライブラリなし）
- データはブラウザの `localStorage` に保存されます（サーバー送信なし）

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | エントリポイント |
| `style.css` | スタイル |
| `script.js` | 記録の追加・保存・集計・グラフ描画ロジック |

## 使い方

1. `index.html` をブラウザで開く
2. 「記録を追加」フォームから日付・種別（入金／出金／運用益／運用損）・金額・メモを入力して追加
3. 上部のサマリーカードとグラフに残高・累計損益が反映される
4. 「CSV書き出し」で記録をCSVファイルとしてダウンロード可能
5. 「全削除」で全記録をリセット可能（元に戻せません）

## 注意

このツールは個人の記録・可視化を目的とした簡易アプリです。税務・法務上の判断（投資会社の資本金処理、金融商品取引法上の登録要否など）は、税理士・弁護士にご確認ください。
